# Knowledge base: what is in, what is missing, what to verify

Every answer in the knowledge base was taken from an official Ebonyi State University web page (ebsu.edu.ng and its subdomains portal., iportal., spgs., services., mail., orphanproject.). The source link is stored with each answer and shown to students. No fact was taken from news sites, blogs or memory.

The official site could not be opened directly from the build machine (it was blocked by the network), so pages were read through a search engine restricted to ebsu.edu.ng. Where the search tool only paraphrased a page, the fact is marked "check" below. Research was done on 9 to 10 October 2026.
